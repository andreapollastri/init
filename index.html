Install

One line. No Homebrew, no global packages, no hosts file edits — the installer scaffolds everything into the current directory.

curl https://init.web.ap.it/bin/go.sh > go.sh && sh go.sh
Requirement: Docker Desktop on macOS must be running before you start.

Quick start

Three steps from an empty folder to a live local app.

01

Run the installer

Paste the install command. The script downloads itself and drives the full setup — no global install needed.

02

Name your project

Choose a subdomain. That name becomes your-name.127001.it — nothing leaves your machine.

03

Open the browser

The script prints app, panel, Mailpit, MinIO, MySQL, and Redis endpoints. Start building.

Take it to production

Once the app is ready locally, deploy Laravel to any Ubuntu VPS with cipi.sh — PHP-FPM, MariaDB, Nginx, Let's Encrypt, zero-downtime releases.

wget -O - https://cipi.sh/setup.sh | bash
  • Full app isolation — own Linux user, PHP-FPM pool & database per app
  • Zero-downtime deploys with instant rollback via Deployer
  • Let's Encrypt SSL, Fail2ban, UFW — automated
  • Multi-PHP, queue workers, S3 backups, auto-deploy webhooks
  • AI agent ready — built-in MCP server for Cursor, VS Code, Claude Desktop
